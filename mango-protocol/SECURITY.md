# Security Policy

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/juliopolycarpo/mango-protocol/security/advisories/new).
Do not open a public issue for a security concern.

Only the latest published minor of each package receives fixes. Protocol-level findings
(a frame that bypasses size bounds, a chunk header that exhausts memory, a decoder that accepts
what the spec refuses) are in scope even when no consumer is affected yet.
