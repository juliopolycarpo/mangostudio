# Ports nativos

Um MangoStudio nativo (WinUI 3 no Windows, GTK 4 + libadwaita no Linux, AppKit no macOS)
usa os **próprios controles** da plataforma e aplica os tokens deste sistema por cima: o
destaque, as superfícies, a escala tipográfica e o espaçamento. O que a plataforma
desenha sozinha (a barra de título, as barras de rolagem, os menus do sistema, o material
da barra lateral do macOS) continua sendo da plataforma. O objetivo é "MangoStudio no
Windows", "MangoStudio no GNOME" e "MangoStudio no Mac", não uma página web numa janela.

As tabelas abaixo associam cada token de cor de [`foundations.md`](./foundations.md) e
cada componente compartilhado de [`components.md`](./components.md). Onde uma
célula diz "aceitar", vale o valor nativo: a diferença é pequena, ou brigar com a
plataforma custaria mais do que economizaria.

## Regras

- **Defina o destaque do app como manga**: `accent` para preenchimentos, `on-accent` para
  texto sobre eles, `accent-fg` para links e itens marcados. No macOS, isso é o asset
  `AccentColor` do app (`NSAccentColorName`).
- **Associe pelo papel, nunca pelo hexadecimal mais próximo.** A linha de cada token
  abaixo nomeia o recurso que cumpre o mesmo papel.
- **Mantenha os pisos de contraste.** `fg-muted` mantém 5.9:1 e `fg-subtle` 4.5:1 em toda
  superfície; texto de status mantém 4.5:1 sobre a própria tinta. Onde a cor de texto
  secundária ou terciária de uma plataforma for mais fraca que isso no tema claro, use o
  próximo recurso mais forte ou o valor do próprio token, como fazem as linhas de texto
  abaixo.
- **`on-accent` continua escuro** (`#241600`) nos dois temas. O texto branco que a
  plataforma usa por padrão sobre o destaque falha na manga (cerca de 2:1), então defina
  o recurso com o valor do token.
- **Use a fonte do sistema** (Segoe UI Variable, Adwaita Sans, SF Pro) e a mono do sistema
  (Cascadia Mono, Adwaita Mono, SF Mono). As pilhas web em `index.css` já caem nelas.
  Mantenha a escala; onde o tamanho de corpo de uma plataforma for diferente (os 13pt do
  macOS), aceite-o.
- **Ícones**: Segoe Fluent Icons, ícones simbólicos do Adwaita ou SF Symbols, no papel do
  ícone Lucide que substituem, nos três tamanhos (`ICON_SM` 14, `ICON_MD` 16, `ICON_LG`
  20).
- **Materiais**: o Mica pode ser o `canvas` da janela no Windows 11, e a barra lateral do
  macOS mantém o material de barra lateral do sistema porque a plataforma a desenha. Nada
  de Acrylic ou vibrancy em cards, menus ou diálogos que o app desenha; nada de
  transparência no GTK.
- **O dialeto de terminal é desenhado pelo app** em toda plataforma, a partir destes
  tokens: os chips `key: value`, o compositor, o anel de contexto, a timeline, os blocos de
  tool e a linha que fecha o turno. São eles que tornam o MangoStudio reconhecível.
