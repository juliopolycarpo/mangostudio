# Native ports

A native MangoStudio (WinUI 3 on Windows, GTK 4 + libadwaita on Linux, AppKit on macOS)
uses the platform's **own controls** and applies this system's tokens on top: the
accent, the surfaces, the type scale and the spacing. What the platform draws itself
(the title bar, scrollbars, system menus, the macOS sidebar material) stays the
platform's. The goal is "MangoStudio on Windows", "MangoStudio on GNOME" and
"MangoStudio on the Mac", not a web page in a window.

The tables below map every colour token in [`foundations.md`](./foundations.md) and
every shared component in [`components.md`](./components.md). Where a cell says
"accept", the native value wins: the difference is small, or fighting the platform
would cost more than it saves.

## Rules

- **Set the app's accent to mango**: `accent` for fills, `on-accent` for text on them,
  `accent-fg` for links and marked items. On macOS that is the app's `AccentColor` asset
  (`NSAccentColorName`).
- **Map by role, never by the nearest hex.** A token's row below names the resource that
  plays the same role.
- **Keep the contrast floors.** `fg-muted` holds 5.9:1 and `fg-subtle` 4.5:1 on every
  surface; status text holds 4.5:1 on its own tint. Where a platform's secondary or
  tertiary text colour is fainter than that in the light theme, use the next stronger
  resource or the token's own value, as the text rows below do.
- **`on-accent` stays dark** (`#241600`) in both themes. A platform default of white text
  on the accent fails on mango (about 2:1), so set the resource to the token.
- **Use the system font** (Segoe UI Variable, Adwaita Sans, SF Pro) and mono (Cascadia
  Mono, Adwaita Mono, SF Mono). The web stacks in `index.css` already fall through to
  them. Keep the scale; where a platform's body size differs (macOS's 13pt), accept it.
- **Icons**: Segoe Fluent Icons, Adwaita symbolic icons or SF Symbols, in the role of the
  Lucide icon they replace, at the three sizes (`ICON_SM` 14, `ICON_MD` 16, `ICON_LG` 20).
- **Materials**: Mica may be the window's `canvas` on Windows 11, and the macOS sidebar
  keeps the system sidebar material because the platform draws it. No Acrylic or
  vibrancy on cards, menus or dialogs the app draws; no transparency on GTK.
- **The terminal dialect is drawn by the app** on every platform, from these tokens: the
  `key: value` chips, the composer, the context ring, the timeline, tool blocks and the
  turn's closing row. They are what makes it recognisably MangoStudio.
